# Using @rabjs/kit

```bash
pnpm add @rabjs/kit
```

## Imports

Named exports only. Three equivalent styles:

```ts
import { chunk, retry } from '@rabjs/kit';
import { chunk } from '@rabjs/kit/array';
import { chunk } from '@rabjs/kit/array/chunk';
```

Do **not** `import kit from '@rabjs/kit'` — there is no default export. `import * as kit from '@rabjs/kit'` is a namespace import, not a default.

### array

- chunk(array, size): Splits an array into chunks of a specified size
- compact(array): Removes falsy values from an array
- difference(array, ...arrays): Creates an array of unique values that are in the first array but not in the other arrays
- drop(array, n): Drops the first n elements from an array
- findIndex(array, predicate): Finds the index of the first element that matches the predicate
- flatten(array, depth): Flattens an array to a specified depth
- flattenDeep(array): Deeply flattens an array
- intersection(...arrays): Creates an array of unique values that are included in all given arrays
- remove(array, predicate): Returns items that match the predicate without mutating the input
- take(array, n): Takes the first n elements from an array
- union(...arrays): Creates an array of unique values that are in any of the given arrays
- uniq(array): Removes duplicate values from an array
- uniqBy(array, iteratee): Removes duplicate values from an array based on a predicate function
- zip(...arrays): Creates an array of grouped elements, the first of which contains the first elements of the given arrays

### collection

- countBy(collection, iteratee): Creates an object composed from the elements of collection grouped by the results of running each element thru iteratee, with counts
- groupBy(collection, iteratee): Creates an object composed from the elements of collection grouped by the results of running each element thru iteratee
- keyBy(collection, iteratee): Creates an object composed from the elements of collection keyed by the results of running each element thru iteratee
- orderBy(collection, iteratees, orders): This method is like sortBy except that it allows specifying the sort orders of the iteratees to sort by
- partition(collection, predicate): Creates an array of elements split into two groups, the first of which contains elements predicate returns truthy for, the second of which contains elements predicate returns falsy for
- sample(collection): Gets a random element from collection
- sampleSize(collection, n): Gets n random elements at unique keys from collection up to the size of collection
- shuffle(collection): Creates an array of shuffled values, using a version of the Fisher-Yates shuffle
- sortBy(collection, iteratees): Creates an array of elements, sorted in ascending order by the results of running each element thru iteratee

### date

- addDays(date, amount): Adds the specified number of days to the given date.
- addMonths(date, amount): Adds the specified number of months to the given date.
- addYears(date, amount): Adds the specified number of years to the given date.
- diffDays(date1, date2): Calculates the number of days between two dates.
- diffMonths(date1, date2): Calculates the number of months between two dates.
- diffYears(date1, date2): Calculates the number of years between two dates.
- endOfDay(date): Returns a new Date object set to the end of the day (23:59:59.999).
- format(date, formatStr): Formats a date according to the given format string. Supported format tokens: - YYYY: 4-digit year - MM: 2-digit month (01-12) - DD: 2-digit day (01-31) - HH: 2-digit hour (00-23) - mm: 2-digit minute (00-59) - ss: 2-digit second (00-59) - SSS: 3-digit millisecond (000-999)
- parse(dateStr, formatStr): Parses a date string according to the given format string. Supported format tokens: - YYYY: 4-digit year - MM: 2-digit month (01-12) - DD: 2-digit day (01-31) - HH: 2-digit hour (00-23) - mm: 2-digit minute (00-59) - ss: 2-digit second (00-59) - SSS: 3-digit millisecond (000-999)
- startOfDay(date): Returns a new Date object set to the start of the day (00:00:00.000).

### function

- bind(func, thisArg, ...partialArgs): Creates a function that invokes func with the this binding of thisArg and partialArgs prepended to the arguments it receives.
- compose(...funcs): Creates a function that is the composition of the provided functions, where each successive invocation is supplied the return value of the previous. Functions are executed from right to left.
- curry(func, arity): Creates a function that accepts arguments of func and either invokes func returning its result, if at least arity number of arguments have been provided, or returns a function that accepts the remaining func arguments, and so on.
- debounce(func, wait, options): Creates a debounced function that delays invoking func until after wait milliseconds have elapsed since the last time the debounced function was invoked.
- memoize(func, resolver): Creates a function that memoizes the result of func. If resolver is provided, it determines the cache key for storing the result based on the arguments provided to the memoized function.
- negate(predicate): Creates a function that negates the result of the predicate func.
- once(func): Creates a function that is restricted to invoking func once. Repeat calls to the function return the value of the first invocation.
- partial(func, ...partialArgs): Creates a function that invokes func with partialArgs prepended to the arguments it receives. This method is like bind except it does not alter the this binding.
- pipe(...funcs): Creates a function that is the composition of the provided functions, where each successive invocation is supplied the return value of the previous. Functions are executed from left to right.
- throttle(func, wait, options): Creates a throttled function that only invokes func at most once per every wait milliseconds.

### math

- maxBy(array, iteratee): This method is like max except that it accepts iteratee which is invoked for each element in array to generate the criterion by which the value is ranked. The iteratee is invoked with one argument: (value).
- meanBy(array, iteratee): This method is like mean except that it accepts iteratee which is invoked for each element in array to generate the value to be averaged. The iteratee is invoked with one argument: (value).
- min(numbers): Computes the minimum value of array. If array is empty or falsey, undefined is returned.
- minBy(array, iteratee): This method is like min except that it accepts iteratee which is invoked for each element in array to generate the criterion by which the value is ranked. The iteratee is invoked with one argument: (value).
- sumBy(array, iteratee): This method is like sum except that it accepts iteratee which is invoked for each element in array to generate the value to be summed. The iteratee is invoked with one argument: (value).

## Native vs kit

Prefer the language builtin when it is the same operation:

| Need                        | Use                                  |
| --------------------------- | ------------------------------------ |
| Flatten one or more levels  | `array.flat(depth)`                  |
| Map then flatten            | `array.flatMap(...)`                 |
| Own keys / values / entries | `Object.keys` / `values` / `entries` |
| Pad a string                | `string.padStart` / `padEnd`         |
| Array check                 | `Array.isArray`                      |

Use `@rabjs/kit` when the operation is not a builtin, needs path/deep semantics, or you want lodash-shaped types:

- `groupBy`, `keyBy`, `partition`, `sortBy`, `orderBy`
- `cloneDeep`, `mergeDeep`, `get`, `set`
- `retry`, `timeout`, `delay` (optional `AbortSignal`)
- `debounce`, `throttle`, `memoize`
- `remove(array, predicate)` — returns matching items; **does not mutate** `array`

Replacing `lodash` / `lodash-es`: [`migrating-lodash-to-kit`](../migrating-lodash-to-kit/SKILL.md).
