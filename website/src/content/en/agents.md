# Agents

@rabjs/kit is meant to be used from coding agents as well as by people. Point an agent at the repo (or at this site) and keep skills in-repo.

## llms.txt

[`llms.txt`](https://github.com/ximing/kit/blob/main/llms.txt) is a generated plain-text index of every public function: name, arguments, and one-line summary. Use it to choose an import without reading source.

It is regenerated by `pnpm docs:catalog` from JSDoc. Do not edit it by hand.

## Skills

Three skills live under [`skills/`](https://github.com/ximing/kit/tree/main/skills):

- [`using-rabjs-kit`](https://github.com/ximing/kit/blob/main/skills/using-rabjs-kit/SKILL.md) — when to pick kit vs native APIs, import styles, immutable `remove`.
- [`adding-kit-function`](https://github.com/ximing/kit/blob/main/skills/adding-kit-function/SKILL.md) — file layout, JSDoc, Vitest, catalog regen.
- [`migrating-lodash-to-kit`](https://github.com/ximing/kit/blob/main/skills/migrating-lodash-to-kit/SKILL.md) — name map, `remove` mutation difference, no `_.chain` / `fp`.

Skills live **only in this repository**. Do not copy them into `~/.grok/skills` or `~/.agents/skills`.

See the [Skills page](/kit/skills) for the `Use when` lines.

## Working in the repo

[`AGENTS.md`](https://github.com/ximing/kit/blob/main/AGENTS.md) is the contract for agents that edit this codebase: named exports only, one function per file, JSDoc + test + `pnpm docs:catalog`, never hand-edit `exports`.
